# Ледовая обстановка Карского моря

Веб-карта: https://zaletnyletchik.github.io/kara-sea-icemap/

Недельные мозаики радара БРЛК «Метеор-М» №2-4 и сцены Sentinel-1 EW (2025–2026) и ледовые продукты по ним:
стадия развития льда, сплочённость и припай по моделям IceUNet (по БРЛК и по Sentinel-1) в сравнении с
обзорными картами ААНИИ. Для каждой недели — снимки, слои продуктов, шторка и слой расхождений, статистика
по районам и временные ряды.

Источники данных: STAC-каталог Роскосмоса (мозаики БРЛК L3M), Sentinel-1 (Copernicus, открытые данные на AWS),
обзорные ледовые карты ААНИИ (SIGRID-3), береговая линия Natural Earth.

Сайт статический и собирается автоматически; внешних запросов не делает. Библиотеки: OpenLayers, proj4js,
шрифты Golos Text и JetBrains Mono (лицензии в `vendor/LICENSES.txt`).
